# BetterJamble Hub — releases

Só os executáveis do BetterJamble Hub. O código fica em outro lugar.

**Baixar:** [BetterJambleHub.exe (última versão)](https://github.com/leoonardo1337/BetterJambleHub-releases/releases/latest/download/BetterJambleHub.exe)

1. Coloque o `BetterJambleHub.exe` numa pasta sua (ex.: Documentos) e abra.
2. Se o Windows avisar "O Windows protegeu o computador": **Mais informações → Executar assim mesmo**.
3. No painel que abre, clique em **Instalar extensão** e siga o passo a passo em cada perfil do Chrome/Brave.

Depois disso ele se atualiza sozinho. Cada versão traz um `latest.json` assinado; o Hub só aceita atualização com essa assinatura.
